# fastmcp's dependency tree (Starlette 1.x) conflicts with the main API's
# pinned FastAPI (which needs Starlette <0.39) — confirmed conflict, not a

# either freezing fastmcp forever or repeatedly upgrading FastAPI across
# major versions just to keep an unrelated tool server compatible), this

# needs enough to query the same Postgres database — nothing web-framework
# related at all.
